Prepare a stock BETAFPV P1 Air

This P1 runs its stock firmware: it needs this preparation before fpvOS can be installed. The page has started step 1 for you. Keep external power connected and disconnect other Artosyn devices.

The same P1 appears as a serial port, a USB bootloader, then a recovery serial port. Your browser asks for permission for each one.

Select its Sirius serial port.

Select the same P1, now called USB download gadget.

Stuck in USB download mode from an earlier try? Power-cycle the P1 to return it to stock, then start again from Connect.

Stock preparation requires desktop Chrome or Edge with Web Serial and WebHID.

After recovery starts, press Connect and select the P1 Air serial port.

Preparation runs in RAM; it does not replace the bootloader. Tested on Linux Chromium; Windows and macOS are not yet verified. Linux may need USB/HID permissions: setup and recovery guide.

My device isn't found
  • Close the vendor's PC tool and any serial terminal: only one program can use the device.
  • Plug the device straight into the computer, and unplug other USB devices such as a flight controller or an ESP32 board.
  • Linux: your user needs access to /dev/ttyACM* (the dialout group), and ModemManager can hold a new port for a few seconds.
